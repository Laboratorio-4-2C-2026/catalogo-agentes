# Reorganización del sprint 2 y del cronograma de Conexia

Documento preparado el 10/11/2026 a partir del relato del autor y una consulta de solo lectura a Jira.

## Uso relatado

Durante el proyecto se utilizó IA para pensar cómo reestructurar el sprint 2 cambiando de lugar elementos del cronograma. El valor del trabajo fue revisar qué convenía realizar primero y cómo organizar el avance; la versión reutilizable exige además explicitar dependencias y capacidad cuando esos datos están disponibles.
