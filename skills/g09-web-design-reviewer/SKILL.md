# Revisión de diseño web

Revisá una página web en ejecución y corregí problemas de diseño cuando el usuario lo solicite.

1. Identificá el flujo, las páginas y los tamaños de pantalla relevantes.
2. Inspeccioná disposición, jerarquía, tipografía, contraste, consistencia, estados y comportamiento responsive.
3. Revisá navegación por teclado, etiquetas, foco y accesibilidad básica.
4. Registrá los hallazgos con evidencia y ubicación. Si corresponde, corregí su origen en el código respetando el diseño existente.
5. Volvé a probar los flujos y tamaños afectados e informá lo que no se pudo comprobar.

## Ejemplo de uso

**Pedido:** Revisá la interfaz de esta página en escritorio y móvil.

**Resultado:** Presenta problemas observados y recomendaciones o correcciones verificadas.
