## Ejemplo de uso

**Pedido:** Con General de Platformance, analizar un proyecto y el período acordado usando sus fuentes autorizadas, y preparar un reporte con evidencia, incertidumbres y recomendaciones para revisión humana.

**Resultado:** JSON conforme al esquema con diagnóstico general, producto, proyecto, ingeniería, personas, evidencia, recomendaciones y respuestas a preguntas. La aplicación puede mostrarlo como reporte y conservar comentarios humanos; guardar o publicar depende del alcance autorizado.

El ejemplo describe el uso, no una nueva ejecución de este borrador. La evidencia visual adjunta es un caso histórico aportado por el autor, separado de la configuración actual recuperada.
